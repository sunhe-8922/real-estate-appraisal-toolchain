# 估价资料搜集清单

> **依据**：GB/T 50291-2015《房地产估价规范》第3.0.5条 + `outputs/房地产评估明细表-计算模板.xlsx` 逐项字段
> **适用方法**：比较法 + 收益法（住宅类估价对象）
> **使用方式**：逐项搜集，每条数据标注来源渠道和信源等级，完成后录入 Excel 模板对应单元格

---

### 5.2 可比实例筛选标准（4.2.3条）

- [ ] **数量≥3**：至少选取3个可比实例
- [ ] **相似性**：与估价对象用途相同、结构相似、位于同一供需圈
- [ ] **时间**：成交日期距价值时点不宜超过1年，不得超过2年
- [ ] **价格类型**：正常交易价格或可修正为正常价格
- [ ] **排除项**：利害关系人交易、缺乏了解的交易、被迫交易、人为哄抬、特殊偏好、相邻合并、受迷信影响（4.2.4条）

## 九、资料检查清单

> **规范依据**：GB/T 50291-2015 第3.0.6条

搜集完成后，逐项检查：

- [ ] **来源可靠性**：每条数据是否标注来源渠道和信源等级
- [ ] **时间有效性**：市场数据日期是否在价值时点前后合理范围内
- [ ] **内容完整性**：交易实例是否包含成交价/日期/面积/楼层/朝向/装修等必要字段
- [ ] **权属原件核验**：估价对象权属证明是否已验原件（3.0.6条强制要求）
- [ ] **数据一致性**：不同来源同一指标是否存在矛盾
- [ ] **异常值排除**：价格明显偏离正常水平的实例是否已标注或排除
- [ ] **可比实例数量**：是否≥3个（4.2.3条）
- [ ] **交易实例时效**：成交日期距价值时点是否≤2年（4.2.3条）
- [ ] **修正系数红线**：单因素修正≤20%，综合修正≤30%（4.2.7条）
- [ ] **价格比红线**：最高/最低比准价格之比≤1.2（4.2.8条）
