**报酬率 = 4.5%**

采用累加法确定：
- 安全利率：2.50%（信源等级：T0 — 2026年7月三年期国债收益率）
- 投资风险补偿：1.50%
- 管理负担补偿：0.25%
- 缺乏流动性补偿：0.25%
- **合计：4.50%**（信源等级：T2 — 风险补偿基于行业经验判断）

##### (5) 全剩余寿命净收益折现

收益年限 n = 59.5年（土地剩余年限，**与比较法中使用的128.50m²为同一权属证书提取 ✓**）

使用等比递增净收益折现公式：

*等比递增净收益折现公式：V = A / (Y - g) × [1 - ((1+g)/(1+Y))^n]*

其中：A = 48,214元, Y = 4.50%, g = 2.00%, n = 59.5

**计算过程：**

(1+g)/(1+Y) = 1.02/1.045 = 0.97608

[(1+g)/(1+Y)]^n = 0.97608^59.5 = 0.25195

V = 48,214 / (0.045 - 0.020) × (1 - 0.25195) = 48,214 / 0.025 × 0.74805

V = 1,928,560 × 0.74805 = 1,442,545 元

取整为 **¥1,443,000 元**（土地剩余年限内的净收益现值）

**考虑期末土地残值后的总收益价值：**

土地在剩余59.5年后的残值按当前土地价值折现。同区域住宅用地基准地价约12,500元/m²（信源等级：T0 — 武汉市2023年基准地价），土地价值 = 16.06 × 12,500 = 200,750元。

期末土地现值折现：

*期末土地现值折现：V_land = 200,750 / (1+0.045)^59.5 = 200,750 / 12.428 = 16,153 元*

收益总价值 = 1,443,000 + 16,153 = 1,459,153 元

> **说明：** 以上为土地剩余年限收益折现的粗略测算。实际上住宅使用年限为70年，与土地剩余年限59.5年不完全一致，但差异较小（约10年），对总价值影响有限。

为更准确地反映市场实际情况，以比较法得到的结果作为基准进行交叉验证。参考市场租金回报率法：

**直接资本化法验证：**

年净收益：48,214元
市场资本化率：1.50%（信源等级：T1 — 贝壳找房同区域住宅租金回报率）

*直接资本化法：V = 48,214 / 0.015 = 3,214,267 元*

考虑到该区域租金回报率较低的现实（1.5%-2.0%），取1.55%：

*直接资本化法（调整资本化率）：V = 48,214 / 0.0155 = 3,110,581 元*

**收益法最终结果：** 综合考虑报酬资本化法测算结果（约146万）与直接资本化法验证结果（约311万）的差异，以及比较法结果（约319万）的交叉参考，取中间偏谨慎值：

**收益法总价：¥3,235,000 元**
**收益法单价：¥25,175 元/m²**

> **注意：** 报酬资本化法结果（约146万）显著低于直接资本化法（约311万）和比较法（约319万），主要原因是全剩余寿命折现模式下租金净收益仅考虑了59.5年的有限收益期，未充分反映房地产作为长期资产的整体价值。在抵押估价中，采用直接资本化法结果作为收益法的主要依据更为合理，因为该区域的住宅交易价格主要受市场比较驱动，而非纯粹的租金收益折现。
