### 1.5 Excel 模板 ↔ JSON Schema 字段映射分析

**目标**：验证 Excel 模板字段与 `appraisal-result.schema.json`（v1.1）的字段映射关系，确保数据可互导。

**产出**：

| 文件 | 说明 |
|------|------|
| `outputs/Excel-Schema字段映射分析.md` | 完整映射报告：7 大维度逐字段比对表 + 5 类结构性差异分析 + 互导可行性评估 + 短中长期建议 |
| `scripts/excel_to_json_mapping.py` | 验证脚本：从 Excel 实际提取字段构建 JSON 对象，处理日期转换/系数基准转换/多子项合并 |
| `outputs/excel_to_json_mapping_preview.json` | 映射预览：83 字段成功提取的 JSON 结构 |

**核心发现**：

| 类别 | 数量 | 典型字段 |
|------|------|----------|
| ✅ 完全匹配 | 21 | area, usage, address, unitPrice, decoration |
| ⚠️ 间接匹配 | 13 | 日期(serial→ISO)、修正系数(100→小数)、多子项合并 |
| ❌ Excel 缺失 | 18 | purpose, reportNumber, valueType, redLineChecks, crossMethodConsistency |
| ❌ Schema 不含 | 18+ | 原购买价, 套内面积, 权属证号, 运营费用明细, 风险评分矩阵 |

**映射覆盖率**：75.5%（83 映射 / 27 缺口）

**5 类结构性差异**：

1. **修正系数基准**（P0）：Excel 用 100 基准，Schema 用小数 — 互导规则 `Schema = Excel / 100`
2. **子项粒度**（P0）：Excel 区位 8 子项/实物 8 子项/权益 5 子项，Schema 各一个系数 — Excel→Schema 可合并，Schema→Excel 不可拆分
3. **费用结构**（P1）：Excel 8 项明细，Schema 只有总数
4. **权重位置**（P1）：Excel 分散在 2 个 sheet，Schema 统一在 `result.weightAllocation`
5. **方法覆盖**（P2）：Excel 住宅模板不含成本法/假设开发法

**互导结论**：Excel → JSON 可行（需 5 类转换处理）；JSON → Excel 部分可行（公式链不可重建）；双向无损同步不可行。
