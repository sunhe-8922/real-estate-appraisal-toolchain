## 三、环境备注（下次验证直接绕坑）

1. **agent-browser / webbridge 的 daemon 均不跨 Bash 工具调用存活**（本环境沙箱行为）——所有浏览器交互必须在**单次命令**内完成，或用 `run_in_background` 常驻 daemon。
2. **本环境 `https_proxy=127.0.0.1:54744` 会劫持 localhost 请求**——webbridge 调用必须 `curl.exe --noproxy "*"`。
3. agent-browser CLI 的 `click` 与 `eval` 上下文不一致（click 报 Done 但事件未达页面）——**用 eval 内 `document.getElementById(id).click()` 合成点击**，行为与真实事件一致（都走 `bindActions` 注册的监听器）。
4. webbridge 的 Chrome 扩展 WS 断连后不自动重连（MV3 service worker 特性），多步验证不可依赖。
