## ⚠️ CRITICAL: 红线约束 (READ FIRST)

**所有测算结果必须满足以下红线，超标不得强行通过：**

1. **可比实例 ≥ 3个**（4.2.3条第1款）— 少于3个则比较法不可用
2. **成交距价值时点 ≤ 2年**（4.2.3条第4款）— 不宜超过1年，不得超过2年
3. **单项修正幅度 ≤ 20%**（4.2.15条第1款）— 交易情况、市场状况、区位、实物、权益任一修正/调整幅度
4. **综合修正幅度 ≤ 30%**（4.2.15条第1款）— 各项修正和调整共同对成交价格的影响
5. **最高价/最低价 ≤ 1.2**（4.2.15条第3款）— 经修正调整后的各可比实例价格比值

**超标处理**：更换可比实例；若无法更换且估价对象特殊，需在报告中说明并陈述理由（4.2.15条第4款）。

## Overview

比较法是房地产估价的**首选方法**（4.1.2条第1款：同类房地产有较多交易的，应选用比较法）。

核心逻辑：选取与估价对象相似的交易实例，经过标准化和修正调整，将可比实例的成交价格转化为估价对象在价值时点的比较价值。

**Reference Material:**
- 规范原文：GB/T 50291-2015 第4.2节（第143-198行）
- 配套技能：`appraisal-data-collection` 负责交易实例搜集，本技能负责测算

**ALWAYS ask yourself first:**
1. "可比实例与估价对象的相似程度够不够？"
2. "每次修正调整是否有量化依据而非拍脑袋？"
3. "修正幅度是否在红线范围内？"
4. "多个可比实例的价格是否收敛（极差 ≤ 1.2）？"

## 一、7 步工作流

### Step 1: 搜集交易实例（4.2.2条）

交易实例信息应包含：
- 交易对象基本状况（位置、面积、楼层、结构、装修等）
- 交易双方基本情况
- 交易方式（协议/招标/拍卖/挂牌）
- 成交日期（精确到日）
- 成交价格、付款方式、融资条件、税费负担
- 交易目的

**数据入口**：使用 `appraisal-data-collection` 技能搜集交易实例，输出交易实例清单。

### Step 2: 选取可比实例（4.2.3-4.2.4条）

从交易实例中筛选可比实例，满足以下条件全部方可通过：

| 条件 | 要求 | 检查 |
|------|------|------|
| 数量 | ≥ 3个 | [ ] |
| 交易方式 | 适合估价目的 | [ ] |
| 相似性 | 与估价对象房地产相似 | [ ] |
| 时效性 | 成交日期距价值时点 ≤ 1年（不宜超过2年） | [ ] |
| 价格正常 | 正常价格或可修正为正常价格 | [ ] |
| 位置优先 | 同等条件下选位置较近、日期较近的 | [ ] |

**排除项（4.2.4条）**：以下交易实例不得选为可比实例：
- 利害关系人之间的交易
- 对市场行情缺乏了解的交易
- 被迫出售或被迫购买
- 人为哄抬价格
- 有特殊偏好的交易
- 相邻房地产合并的交易
- 受迷信影响的交易

### Step 3: 建立比较基础（4.2.6条）

对可比实例成交价格进行**标准化处理**，五项统一：

| 统一项 | 操作 | 公式示例 |
|--------|------|---------|
| 财产范围 | 消除范围差异（如含车位/不含车位） | 调整额 = 车位市场价 |
| 付款方式 | 非一次性→调整为成交日一次性付清 | 折现调整 |
| 融资条件 | 非常规融资→调整为常规融资 | 利率差异调整 |
| 税费负担 | 非正常负担→调整为正常负担 | 卖方净得价 + 正常税费 |
| 计价单位 | 统一总价/单价、币种、面积内涵 | 汇率换算、面积折算 |

### Step 4: 交易情况修正（4.2.7条）

**目标**：消除特殊交易情况造成的成交价格偏差，将非正常成交价格修正为正常价格。

适用场景：当正常可比实例不足3个时，可将特殊交易实例纳入，但必须量化修正。正常交易实例无需此步骤。

| 特殊交易情况 | 修正方向 | 修正依据 |
|-------------|---------|---------|
| 利害关系人交易 | 偏低→调高 或 偏高→调低 | 调查偏离正常水平的幅度 |
| 被迫出售 | 偏低→调高 | 评估急售折扣率 |
| 人为哄抬 | 偏高→调低 | 分析正常市场水平 |
| 特殊偏好 | 偏高→调低 | 量化偏好溢价 |

**修正方式**：可采用金额（±元/m²）、百分比（× (1±a%)）或回归分析法。

### Step 5: 市场状况调整（4.2.8条）

**目标**：消除成交日期与价值时点之间的市场价格变动，将成交日期价格调整为价值时点价格。

```
调整后价格 = 可比实例成交价格 × (价值时点价格指数 / 成交日期价格指数)
```

**调整依据**：可比实例所在地同类房地产的价格变动率或价格指数，来源必须真实、可靠。

**数据来源**：
- T0：统计局/住建部门发布的价格指数
- T1：头部房地产平台同区域同类型价格走势
- T2：中介机构报价——仅作参考，须交叉验证

### Step 6: 房地产状况调整（4.2.9-4.2.13条）

**目标**：消除可比实例与估价对象之间的状况差异，三大维度逐项调整：

#### 6.1 区位状况调整（4.2.10条）

将可比实例区位状况→调整为估价对象区位状况。

| 调整因素 | 比较内容 | 量化方法 |
|---------|---------|---------|
| 位置 | 距市中心/商圈/交通枢纽距离 | 距离衰减系数 |
| 交通 | 公交/地铁线路数、站点距离 | 交通便利度打分 |
| 外部配套设施 | 学校/医院/商超/公园 | 设施完备度打分 |
| 周围环境 | 景观/噪音/空气质量 | 环境质量系数 |
| 楼层（住宅） | 所处楼层 | 楼层修正系数 |
| 朝向（住宅） | 南/东南/东/其他 | 朝向修正系数 |

#### 6.2 实物状况调整（4.2.11条）

| 土地因素 | 建筑物因素 |
|---------|-----------|
| 面积 | 建筑规模（面积） |
| 形状 | 建筑结构 |
| 地形 | 设施设备 |
| 地势 | 装饰装修 |
| 地质 | 空间布局 |
| 开发程度 | 建筑功能/外观 |
| — | 新旧程度 |

#### 6.3 权益状况调整（4.2.12条）

| 调整因素 | 说明 |
|---------|------|
| 规划条件 | 容积率、建筑密度、限高 |
| 土地使用期限 | 剩余年限差异 |
| 共有情况 | 按份/共同共有 |
| 用益物权 | 地役权等 |
| 租赁/占用 | 带租约 vs 空置 |
| 查封/限制 | 权利受限状况 |
| 拖欠税费 | 税费欠缴 |

**调整方式**（4.2.14条）：基于总价或单价，采用金额、百分比或回归分析法，通过直接比较或间接比较进行。

### Step 7: 计算比较价值（4.2.16条）

对修正调整后的可比实例价格进行综合，方法选择：

| 方法 | 适用条件 | 公式 |
|------|---------|------|
| 简单算术平均 | 各实例差异不大 | V = (V₁+V₂+...+Vₙ)/n |
| 加权算术平均 | 实例相似度/可靠度差异大 | V = Σ(wᵢ×Vᵢ) |
| 中位数 | 有极端值但不宜剔除 | V = median(V₁...Vₙ) |

**权重考虑因素**：
- 可比实例与估价对象的相似程度（越相似权重越大）
- 可比实例资料的可靠程度（越可靠权重越大）
- 修正调整幅度大小（幅度越小权重越大）

## 二、修正调整幅度监控

每次测算完成后，检查以下幅度约束：

```
单项修正幅度 = |(修正后价格 - 修正前价格) / 修正前价格|
综合修正幅度 = |(最终调整后价格 - 原始成交价格) / 原始成交价格|
价格极差比 = max(调整后价格) / min(调整后价格)
```

| 约束 | 红线 | 状态 |
|------|------|------|
| 交易情况修正幅度 | ≤ 20% | [ ] |
| 市场状况调整幅度 | ≤ 20% | [ ] |
| 区位状况调整幅度 | ≤ 20% | [ ] |
| 实物状况调整幅度 | ≤ 20% | [ ] |
| 权益状况调整幅度 | ≤ 20% | [ ] |
| 综合修正幅度 | ≤ 30% | [ ] |
| 价格极差比 | ≤ 1.2 | [ ] |

## 七、持续改进

After completing 比较法测算, ask:

1. 是否有更相似、更近期的可比实例可以替换？
2. 修正调整系数的来源是否可进一步升级（T2→T1/T0）？
