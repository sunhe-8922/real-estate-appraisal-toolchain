# 搜集估价所需资料

根据 GB/T 50291-2015 第3章估价程序第4步（3.0.5条），系统化搜集房地产估价所需资料，覆盖估价对象状况、市场交易实例、收益成本数据、区域与宏观影响因素四大维度。

## Workflow

### Step 1: 明确估价基本事项

在搜集资料前，必须先确定四要素（3.0.3条），它决定了资料搜集的方向和范围：

- **估价目的**：抵押？税收？征收？转让？租赁？——不同目的对应不同资料侧重
- **价值时点**：具体到日——决定数据的时间口径
- **估价对象**：财产范围 + 空间范围——决定需要哪些实物/权益资料
- **价值类型**：市场价值？抵押价值？投资价值？——决定数据口径

确认后，输出一份《估价项目资料需求摘要》：

| 要素 | 内容 | 对资料搜集的影响 |
|------|------|------------------|
| 估价目的 | [填写] | [影响数据类型侧重] |
| 价值时点 | [填写] | [影响数据时间口径] |
| 估价对象 | [填写] | [影响实物/权益资料范围] |
| 价值类型 | [填写] | [影响数据口径] |

### Step 2: 估价方法适用性预判

根据估价对象特征及市场状况，预判适用的估价方法（4.1.2条），据此确定资料搜集重点：

| 估价对象特征 | 预判方法 | 资料搜集重点 |
|-------------|---------|-------------|
| 同类房地产有较多交易 | 比较法 | 交易实例数据 |
| 有租金等经济收入 | 收益法 | 收益/运营费用数据 |
| 可假定为独立开发建设项目 | 成本法 | 重置成本/折旧数据 |
| 有开发或再开发潜力 | 假设开发法 | 开发支出/完成后价值数据 |

适用多种方法时，需同时搜集所有方法的资料，不得随意取舍。

### Step 3: 搜集估价对象状况资料

**3.0.5 第1项：反映估价对象区位、实物和权益状况的资料**

#### 3.1 区位状况

| 资料项 | 具体内容 | 来源渠道 |
|--------|---------|---------|
| 位置 | 地址、坐标、在城市中的方位 | 委托人提供、实地查勘、地图工具 |
| 交通 | 公共交通站点距离、道路通达度、停车条件 | 实地查勘、交通规划部门 |
| 周边环境 | 商服设施、教育医疗、自然景观、污染源 | 实地查勘、城市规划部门 |
| 规划限制 | 容积率、建筑密度、限高、用途管制 | 自然资源/规划部门、控规文件 |

#### 3.2 实物状况

| 资料项 | 具体内容 | 来源渠道 |
|--------|---------|---------|
| 土地 | 面积、形状、地势、地质、开发程度 | 权属证明、实地查勘 |
| 建筑物 | 面积、层数、结构、装修、设备、建成年代 | 房产证、竣工图、实地查勘 |
| 使用状况 | 维护保养、改造装修、使用强度 | 实地查勘、物业记录 |
| 缺陷 | 质量缺陷、安全隐患、环境污染 | 实地查勘、专业鉴定报告 |

#### 3.3 权益状况

| 资料项 | 具体内容 | 来源渠道 |
|--------|---------|---------|
| 权属证明 | 不动产权证/房产证/土地证原件 | 委托人提供（须验原件） |
| 他项权利 | 抵押权、地役权、租赁权等 | 不动产登记中心查询 |
| 权利限制 | 查封、异议登记、预告登记 | 法院/不动产登记中心 |
| 土地性质 | 出让/划拨、使用年限、剩余年限 | 权属证明、出让合同 |
| 共有情况 | 按份共有/共同共有、份额 | 权属证明 |

**注意（3.0.6条）**：委托人是估价对象权利人时，须查看权属证明原件，复印件须与原件核对，不得仅凭复印件判断权属状况。

### Step 4: 搜集交易实例资料

**3.0.5 第2项之一：交易资料——比较法所需**

#### 4.1 交易实例数据

| 资料项 | 具体内容 | 来源渠道 |
|--------|---------|---------|
| 成交价格 | 总价、单价、含税/不含税 | 房地产交易平台、中介机构 |
| 成交日期 | 精确到日 | 交易平台、备案系统 |
| 交易方式 | 协议/招标/拍卖、挂牌 | 交易平台公告 |
| 交易情况 | 正常/非正常、利害关系人、特殊偏好 | 调查核实 |
| 房地产状况 | 位置、面积、楼层、朝向、装修、年限 | 交易平台、实地核实 |

#### 4.2 可比实例筛选

从交易实例中选取可比实例（4.2.3条），须满足：

- [ ] **数量**：不少于三个
- [ ] **交易方式**：适合估价目的
- [ ] **相似性**：与估价对象房地产相似
- [ ] **时间**：成交日期距价值时点不宜超过一年，不得超过两年
- [ ] **价格**：正常价格或可修正为正常价格

**排除项（4.2.4条）**：利害关系人交易、缺乏了解的交易、被迫交易、人为哄抬、特殊偏好、相邻合并、受迷信影响。

### Step 5: 搜集收益与成本资料

**3.0.5 第2项之二/三：收益、成本资料——收益法/成本法/假设开发法所需**

#### 5.1 收益法资料

| 资料项 | 具体内容 | 来源渠道 |
|--------|---------|---------|
| 租金水平 | 毛租金、净租金、租金增长率 | 中介机构、租赁备案、市场调研 |
| 空置率 | 正常空置率、收租损失率 | 行业报告、中介统计 |
| 运营费用 | 房产税、保险、物业、管理、维修、水电 | 物业公司、委托人提供 |
| 报酬率参数 | 安全利率、风险调整值 | 银行利率、市场提取（≥3实例） |
| 收益期/持有期 | 土地剩余年限、建筑物经济寿命 | 权属证明、建筑评估 |

#### 5.2 成本法资料

| 资料项 | 具体内容 | 来源渠道 |
|--------|---------|---------|
| 土地成本 | 土地取得费用、土地开发费用 | 土地成交公告、政府部门 |
| 建设成本 | 建安工程费、前期工程费、基础设施建设费 | 工程造价信息、造价咨询机构 |
| 管理费用 | 按建设成本比例 | 行业标准 |
| 销售费用 | 营销推广费 | 行业标准 |
| 投资利息 | 利率、计息周期 | 银行贷款利率 |
| 销售税费 | 税费种类及税率 | 税务部门 |
| 开发利润 | 同类开发项目利润率 | 行业研究 |
| 折旧数据 | 建成年代、物质/功能/外部折旧因素 | 实地查勘、市场比较 |

#### 5.3 假设开发法资料

| 资料项 | 具体内容 | 来源渠道 |
|--------|---------|---------|
| 后续开发期 | 前期、建造期、销售期 | 类似项目工期 |
| 后续开发支出 | 继续建造成本、管理费、销售费 | 工程造价信息 |
| 开发完成后价值 | **不得用成本法测算**（4.5.7条），须用比较法/收益法 | 市场比较/收益测算 |
| 折现率/应得利润 | 类似项目投资回报率 | 市场调研 |

### Step 6: 搜集区域市场资料

**3.0.5 第3项：对估价对象所在地区房地产价值价格有影响的资料**

| 资料项 | 具体内容 | 来源渠道 |
|--------|---------|---------|
| 区域规划 | 总体规划、控规调整、片区更新 | 规划部门官网 |
| 基础设施 | 交通、教育、医疗、商业新增/变更 | 政府公告、实地调查 |
| 区域市场动态 | 供需状况、价格走势、成交量 | 房地产交易网、统计局 |
| 环境变化 | 污染源新增/消除、景观改变 | 环保部门、实地调查 |
| 政策影响 | 限购/限贷/税收/学区调整政策 | 政府公告 |

### Step 7: 搜集宏观影响资料

**3.0.5 第4项：对房地产价值价格有普遍影响的资料**

| 资料项 | 具体内容 | 来源渠道 |
|--------|---------|---------|
| 宏观经济 | GDP增速、CPI、居民收入 | 统计局 |
| 货币政策 | 利率政策、信贷政策 | 央行、银保监会 |
| 房地产政策 | 全国性调控政策、土地政策 | 国务院、住建部、自然资源部 |
| 税收政策 | 房产税试点、契税调整 | 税务总局 |
| 市场情绪 | 市场预期、消费者信心 | 行业报告、新闻 |

### Step 8: 资料检查与核实

**3.0.6条要求：对搜集的资料应进行检查。**

逐项检查清单：

- [ ] **来源可靠性**：数据来源是否为权威渠道（T0/T1/T2分级）
- [ ] **时间有效性**：数据日期是否在价值时点前后合理范围内
- [ ] **内容完整性**：每条交易实例/收益数据是否包含必要字段
- [ ] **权属原件**：估价对象权属证明是否已验原件（3.0.6条强制要求）
- [ ] **数据一致性**：不同来源同一指标是否存在矛盾
- [ ] **异常值排除**：价格明显偏离正常水平的实例是否已标注或排除

**信源分级标准**：
- **T0（直接采信）**：政府公开数据、不动产登记中心、官方统计
- **T1（交叉验证后采信）**：头部房地产平台、银行评估数据、行业协会
- **T2（仅作线索）**：中介报价、自媒体分析——须找到 T0/T1 交叉验证

### Step 9: 输出

生成《估价资料搜集清单》文档，格式：

1. **项目概况**：估价目的、对象、时点、方法
2. **资料清单总表**：按本技能 Step 3-7 的 7 大维度汇总
3. **来源渠道标注**：每条数据标注来源及信源等级
4. **缺口提示**：列出尚未获取的关键资料及建议获取途径
5. **检查记录**：Step 8 检查清单的执行结果

## Important Notes

- **资料与方法的匹配**：不同估价方法需要的资料不同，Step 2 的方法预判决定了 Step 4-5 的搜集重点。适用多种方法时须同时收集所有方法所需资料，不得随意取舍（4.1.3条）
- **原件核验红线**：估价对象权属证明必须验原件，这是 3.0.6 条的强制性规定
- **时间口径一致**：所有市场数据的时间口径须与价值时点一致或可调整至价值时点
- **交易实例时效**：成交日期距价值时点不宜超过一年、不得超过两年（4.2.3条）
- **假设开发法特殊约束**：开发完成后价值不得采用成本法测算（4.5.7条），须用比较法或收益法数据
- **资料保存**：所有估价资料须保存至少 10 年（3.0.14条）
- **实地查勘补充**：资料搜集与实地查勘（Step 5 of 估价程序）是互补的，实地查勘中发现的资料须补充搜集（3.0.7条）
- **专业问题转介**：房屋安全、质量缺陷、环境污染等专业外问题，建议委托专业机构鉴定（3.0.10条）
