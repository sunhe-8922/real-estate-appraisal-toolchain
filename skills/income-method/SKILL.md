## ⚠️ CRITICAL: 方法选择与数据约束 (READ FIRST)

**收益法核心决策树：**

1. **FIRST: 选择具体方法** — 优先选用报酬资本化法（4.3.2条）
2. **选择模式** — 收益期较长难预测 → 持有加转售模式；收益期稳定 → 全剩余寿命模式
3. **ONLY if 资本化率可靠:** 可选用直接资本化法作为辅助验证
4. **NEVER 用非正常客观数据** — 除租约限制外，收入/费用必须取正常客观值（4.3.10条）
5. **NEVER 忽略最近三年实际数据** — 测算净收益时必须调查至少三年历史（4.3.11条）

**Why this matters:** 收益法的理论最完善但参数最难确定——报酬率和净收益预测的微小偏差会被公式放大，导致结果失实。

## Overview

收益法的核心：**房地产价值 = 未来净收益的现值之和**。适用于有经济收益的房地产，是商业地产估价的必备方法。

**三种计算公式：**

| 方法 | 公式 | 适用场景 |
|------|------|---------|
| 全剩余寿命模式 | V = Σ Aᵢ/(1+Yᵢ)ⁱ | 收益期可完整预测 |
| 持有加转售模式 | V = Σ Aᵢ/(1+Yᵢ)ⁱ + Vₜ/(1+Yₜ)ᵗ | 长期持有，转售退出 |
| 直接资本化法 | V = NOI / R | 净收益稳定，资本化率可靠 |

## 一、6 步工作流

### Step 1: 选择具体估价方法（4.3.1-4.3.2条）

```
评估对象有收益？
├─ 是 → 收益法适用
│   ├─ 优先：报酬资本化法
│   │   ├─ 收益期较短或可预测 → 全剩余寿命模式 (4.3.3)
│   │   └─ 收益期较长难预测 → 持有加转售模式 (4.3.4)
│   └─ 辅助验证：直接资本化法 (4.3.5)
│       └─ 条件：资本化率可靠、净收益稳定
└─ 否 → 收益法不适用，用成本法
```

**决策输出**：明确选用哪种方法/模式及理由。

### Step 2: 测算收益期或持有期（4.3.6-4.3.7条）

#### 收益期（全剩余寿命模式）

| 情形 | 收益期取值 |
|------|-----------|
| 土地使用权与建筑物经济寿命同时结束 | 任取其一 |
| 两者不同时结束 | **取较短者** |
| 超出收益期的土地使用权 | 按4.3.16条另行处理 |
| 承租人权益价值 | 剩余租赁期限 |

#### 持有期（持有加转售模式）

- **宜为 5～10年**（4.3.7条）
- 根据市场投资者典型持有时间和可预测期间收益的期限确定

### Step 3: 测算未来收益（4.3.8-4.3.13条）

#### 3.1 租赁收入法（4.3.8条）— 优先选用

```
潜在毛租金收入 (PGI)
- 空置和收租损失
= 有效毛收入 (EGI)
+ 其他收入（押金利息等）
- 运营费用（由出租人负担的部分）
= 净收益 (NOI)
```

**运营费用构成**（4.3.8条第3款）：
- 房地产税
- 房屋保险费
- 物业服务费
- 管理费用
- 维修费
- 水电费（维持正常使用的）

**注意**：由承租人负担的运营费用不计入。

#### 3.2 经营收入法（4.3.9条）— 无租赁收入时

| 类型 | 净收益公式 | 适用场景 |
|------|-----------|---------|
| 商服经营型 | 经营收入 - 经营成本 - 经营费用 - 税金及附加 - 管理费用 - 财务费用 - 经营者利润 | 酒店、商场、餐饮 |
| 生产型 | 销售收入 - 生产成本 - 销售费用 - 税金及附加 - 管理费用 - 财务费用 - 生产者利润 | 厂房、仓库 |
| 自用/尚未使用 | 比照类似有收益房地产资料 | 空置商用物业 |

#### 3.3 租约处理规则（4.3.10条）

| 评估目的 | 租金取值 |
|---------|---------|
| 出租人权益价值 | 已出租部分租赁期内按合同租金，其余按市场租金 |
| 承租人权益价值 | 净收益 = 市场租金 - 合同租金 |
| 无租约限制价值 | 全部按市场租金 |

**⚠️ 合同租金明显偏离市场租金时**：调查租赁合同真实性，分析解除合同的可能性及影响。

#### 3.4 历史数据校验（4.3.11条）

- 价值时点为现在时：**必须调查至少最近三年**实际收入/费用/净收益
- 历史数据与正常客观数据有差异时：分析原因并修正

### Step 4: 确定报酬率或资本化率（4.3.14-4.3.15条）

#### 报酬率 — 三种方法

| 方法 | 原理 | 要求 |
|------|------|------|
| **市场提取法** | 利用可比实例价格和净收益反推 Y | ≥ 3个可比实例 |
| **累加法** | Y = 安全利率 + 风险调整值 | 安全利率用一年定期/国债利率 |
| **投资收益率排序插入法** | 与其他投资品种比较风险排序 | 充分了解各品种风险收益 |

#### 资本化率 — 直接资本化法用

- 优先：市场提取法
- 综合资本化率还可采用：
  - 抵押贷款+权益资金加权：R₀ = M·Rᴍ + (1-M)·Rᴇ
  - 土地+建筑物加权：R₀ = L·Rʟ + B·Rʙ

### Step 5: 计算收益价值（4.3.16-4.3.17条）

#### 报酬资本化法 — 全剩余寿命模式

```
V = A₁/(1+Y₁) + A₂/(1+Y₂)² + ... + Aₙ/(1+Yₙ)ⁿ
```

#### 报酬资本化法 — 持有加转售模式

```
V = Σᵗ Aᵢ/(1+Yᵢ)ⁱ + Vₜ/(1+Yₜ)ᵗ
```

其中 Vₜ（期末转售收益）= 持有期末转售价格 - 转售成本（销售费用+税费）

**⚠️ 期末转售价格不得用成本法测算！** 须采用直接资本化法或比较法。

#### 直接资本化法

```
V = NOI / R
```

#### 特殊处理（4.3.16条）

| 情形 | 处理方式 |
|------|---------|
| 土地剩余年限 > 建筑物经济寿命 | 收益期价值 + 剩余土地价值 |
| 建筑物经济寿命 > 土地剩余年限（无偿收回） | 仅取收益期内价值 |
| 建筑物经济寿命 > 土地剩余年限（未约定无偿收回） | 收益期价值 + 期末建筑物折现价值 |

### Step 6: 期末转售收益测算

持有期末的转售价格可采用：
- **直接资本化法**：Vₜ = NOIₜ₊₁ / Rₜ
- **比较法**：预测持有期末同类房地产价格

转售成本 = 转让人负担的销售费用 + 销售税费（4.3.12条）。

## 二、关键约束

| 约束 | 出处 |
|------|------|
| 优先选用报酬资本化法 | 4.3.2 |
| 收入/费用取正常客观值（租约限制除外） | 4.3.10-1 |
| 调查至少最近三年实际数据 | 4.3.11 |
| 报酬率市场提取法 ≥ 3个可比实例 | 4.3.14-1 |
| 期末转售价格不得用成本法 | 4.5.7（参照） |
| 持有期宜为5～10年 | 4.3.7 |

输出时根据用户需求选择模式。

### 3.2 切换测算方法与模式

模板默认使用**报酬资本化法-全剩余寿命模式**。用户可在 Excel 中切换：

**切换为持有加转售模式：**
1. Sheet2 行3 输入持有期年数
2. 填写行 N+5 的期末转售收益和行 N+6 的期末报酬率
3. 收益总价值自动包含期末转售折现项

**切换为直接资本化法：**
1. 在 Sheet2 新建区域，输入资本化率 R
2. 公式简化为 `=净收益测算!B17 / R`
3. 删除折现行区域（保留 Sheet1 净收益测算不变）

### 3.3 调整收益期/折现期

模板默认生成 5 年折现，用户可扩展：

1. 在 Sheet2 行3 修改收益期年数
2. 选中最后一行折现行（含公式），向下拖拽填充至目标年数
3. 所有折现系数、现值自动重算
4. 收益价值公式范围自动更新（SUM 覆盖全部年份）

### 3.4 自定义运营费用项目

模板默认列出 7 项运营费用（行9-15），用户可：

- **增加费用项**：在行15 后插入行，填入费用名称和金额，费用合计公式自动扩展
- **删除费用项**：删除对应行，SUM 公式范围自动调整
- **重命名费用项**：直接在 A 列修改名称即可
