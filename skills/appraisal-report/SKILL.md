## ⚠️ CRITICAL: 报告合规红线 (READ FIRST)

**报告内容必须满足 GB/T 50291-2015 第7章全部要求：**

1. **估价方法 ≥ 2种**（7.0.1条注）— 除技术路线限制外，报告至少采用两种方法
2. **方法适用性必须分析**（7.0.14条）— 未选用的方法需说明不适用的理由
3. **估价结果必须经交叉校核**（7.0.15条）— 各方法结果需校核并说明差异原因
4. **假设和限制条件必须完整**（7.0.16条）— 一般假设 + 特殊假设 + 估价报告使用限制
5. **估价结果汇总表格式合规**（7.0.17条）— 表7.0.17-1 格式，含各方法结果与最终估值
6. **测算轨迹必须可追溯**（7.0.12条）— 附测算过程，参数有来源
7. **报告使用期限 ≤ 1年**（7.0.17-14条）— 自出具日起不超过1年，超期自动失效
8. **参数来源必须标注信源等级** — 按 T0(官方)/T1(头部机构)/T2(自媒体) 三级标注，与 web-research-methodology 协同
9. **禁止使用 LaTeX 公式块 `$$...$$`** — WorkBuddy 内置 Markdown 查看器不支持 LaTeX 渲染。数学公式使用纯文本表示（如 `V = A / (Y - g) × [1 - ((1+g)/(1+Y))^n]`）
10. **输出路径禁止放在 `.workbuddy/` 目录下** — 该目录文件无法通过内置查看器显示。输出到 `[工作区根目录]/outputs/[项目名称]_估价报告.md`

**Why this matters:** 估价报告是法定文书，内容缺失或格式不规范可能导致报告被退审、招标被否决、甚至承担法律责任。

## Overview

估价报告是估价工作的**最终交付物**。核心任务：将各方法测算结果（比较法/收益法/成本法/假设开发法）按规范第7章要求汇编为结构完整、格式规范的正式报告。

**报告类型决策树（7.0.2条）：**
```
估价目的和对象复杂程度
├─ 简单项目 → 表格式报告
└─ 复杂项目 → 叙述式报告
    ├─ 完整报告 = 结果报告 + 技术报告
    └─ 简要报告 = 仅结果报告（特定场景）
```

## 一、6 步工作流

### Step 1: 确认报告类型与范围

**Define Scope:**

| 决策项 | 选项 | 依据 |
|--------|------|------|
| 报告类型 | 叙述式 / 表格式 | 7.0.2条：对象复杂程度和估价目的 |
| 报告深度 | 完整报告 / 简要报告 | 7.0.1条：估价目的决定是否需技术报告 |
| 估价目的 | 抵押/征收/司法拍卖/转让/租赁/课税/其他 | 决定前提、方法选择和报告侧重点 |
| 估价方法 | 比较法/收益法/成本法/假设开发法 | 至少两种，未选用的必须说明理由 |
| 输出格式 | Markdown/Word/HTML/PDF/Dashboard | 用户指定，默认 Markdown |

**交付物清单：**

```markdown
□ 封面
□ 目录
□ 致估价委托人函
□ 注册房地产估价师声明
□ 估价的假设和限制条件
□ 估价结果报告（含结果汇总表 7.0.17-1）
□ 估价技术报告（含各方法测算轨迹）
□ 附件（区位图/照片/权属证明/可比实例清单/委托书复印件等）
```

### Step 2: 收集测算结果与基础信息

**从各测算技能收集以下数据：**

| 数据项 | 来源技能 | 格式 |
|--------|---------|------|
| 比较价值 + 可比实例明细 + 修正系数 | comps-method | .xlsx 或结构化 JSON |
| 收益价值 + 净收益 + 报酬率 | income-method | .xlsx |
| 成本价值 + 各项支出 + 折旧 | cost-method | .xlsx |
| 开发价值 + 红线检查 | hypothetical-dev-method | .xlsx |
| 估价对象资料 | appraisal-data-collection | 结构化文档 |

**收集校验：**
- [ ] 每个方法的结果已通过内部红线检查
- [ ] 各方法结果差异已在合理范围内（否则需分析原因）
- [ ] 所有参数来源已标注信源等级
- [ ] 现场查勘记录完整（含照片和日期）

### Step 3: 撰写报告各章节

按照 GB/T 50291-2015 第7章要求，逐章撰写：

#### 3.0 封面（7.0.4条）

**封面必须包含以下7项信息：**

```markdown
# 房地产估价报告

**估价项目名称：** {{项目名称}}
**估价委托人：** {{委托人}}
**估价机构：** {{机构名称}}
**注册房地产估价师：** {{估价师姓名}}（注册号：{{估价师注册号}}）
**估价报告出具日期：** {{出具日期}}
**估价报告编号：** {{报告编号}}

（本页为封面，后续为目录和正文）
```

**Word/PDF 封面要求：**
- 标题「房地产估价报告」：黑体 22pt，居中，加粗
- 项目信息：宋体 14pt，1.5倍行距，左对齐
- 估价机构盖章处预留空白
- 封面不编页码

#### 3.0b 目录（7.0.17条配套）

**目录自动生成规则：**
- Markdown：使用 `<!-- TOC -->` 标记位，生成时自动替换为带锚点的目录列表
- Word：使用 python-docx 的 Heading 样式 + 自动生成目录域代码

```markdown
   4.2 估价机构
   ...

```

#### 3.1 致估价委托人函（7.0.5条）

必须包含：
- 致函对象（估价委托人全称）
- 估价目的（明确唯一目的）
- 估价对象（范围、名称、坐落、规模、用途、权属）
- 价值时点（具体日期）
- 价值类型（价值定义及内涵）
- 估价方法（列出所用方法）
- 估价结果（总价 + 单价，大写 + 小写，**必须标注币种**）
- 估价报告使用期限（自报告出具日起不超过1年）
- 特别提示（使用限制和假设说明）
- 估价机构盖章、估价师签章、出具日期

#### 3.2 注册房地产估价师声明（7.0.6条）

标准声明模板（8项必须声明）：
1. 独立客观公正，与当事人无利害关系
2. 已实地查勘，查勘日期
3. 已对估价对象进行权属调查
4. 报告依据国家标准出具
5. 没有人对本报告提供重要专业帮助（如有则说明）
   - **专业帮助说明模板：**「[姓名]（[专业背景/资质]）对[具体估价环节]提供了专业帮助，具体内容为[简述]。该专业帮助已被充分核实并合理采纳。」
6. 遵循估价职业道德
7. 估价对象状况与价值时点一致
8. 不得修改本声明

#### 3.3 估价的假设和限制条件（7.0.16条）

**一般假设：**
- [ ] 交易假设（假设估价对象处在交易过程中）
- [ ] 市场条件假设（公开市场、自愿交易）
- [ ] 权属完整假设（所有权/使用权无瑕疵）
- [ ] 持续使用假设（按现状/规划用途持续使用）
- [ ] 资料真实假设（委托人提供资料真实、合法、准确、完整）
- [ ] 未定事项假设（对权属、面积、用途等未定事项做合理假设）

**特殊假设（按估价目的选择）：**

| 估价目的 | 需增加的假设 |
|---------|------------|
| 抵押估价 | 优先受偿权假设、变现能力分析假设 |
| 征收估价 | 不考虑抵押/查封/租赁限制 |
| 司法拍卖 | 快速变现假设、税费负担假设 |
| 出让估价 | 宗地外基础设施完备假设 |

**估价报告使用限制：**
- 报告用途限制（仅用于估价目的）
- 使用期限限制（不超过1年）
- 报告使用人限制
- 报告完整使用要求

#### 3.4 估价结果报告（7.0.17条）

| 条款 | 内容 | 写作要求 |
|------|------|---------|
| 7.0.17-1 | 估价委托人 | 名称、住所、联系方式 |
| 7.0.17-2 | 估价机构 | 全称、资质等级、备案证书号 |
| 7.0.17-3 | 估价目的 | 唯一、明确 |
| 7.0.17-4 | 估价对象 | 范围、坐落、用途、面积、权属、实物/区位/权益状况 |
| 7.0.17-5 | 价值时点 | 年月日 |
| 7.0.17-6 | 价值类型 | 定义及内涵 |
| 7.0.17-7 | 估价原则 | 独立客观公正 + 5项技术原则 |
| 7.0.17-8 | 估价依据 | 法律法规 + 技术标准 + 委托人提供资料 |
| 7.0.17-9 | 估价方法 | 所用方法 + 未用方法及理由 |
| 7.0.17-10 | 估价结果 | 总价 + 单价 + 币种 |
| 7.0.17-11 | 注册估价师 | 姓名、注册号、签章 |
| 7.0.17-12 | 实地查勘期 | 起止日期 |
| 7.0.17-13 | 估价作业期 | 起止日期 |
| 7.0.17-14 | 报告使用期限 | 起止日期 |

#### 3.5 估价结果汇总表（7.0.17-1）

**表 7.0.17-1 标准格式（必须包含）：**

| 估价方法 | 估价结果 | 测算结果 |
|---------|---------|---------|
| 比较法 | 总价 (万元) | xxx |
| | 单价 (元/m²) | xxx |
| 收益法 | 总价 (万元) | xxx |
| | 单价 (元/m²) | xxx |
| 成本法 | 总价 (万元) | xxx |
| | 单价 (元/m²) | xxx |
| 假设开发法 | 总价 (万元) | xxx |
| | 单价 (元/m²) | xxx |
| **最终估价结果** | **总价 (万元)** | **xxx** |
| | **单价 (元/m²)** | **xxx** |

**最终结果的确定方式：**
- 算术平均 / 加权平均 / 以某方法为主
- 必须说明权重分配的理由

#### 3.6 估价技术报告（可选，完整报告必含）

**A. 估价对象分析（7.0.9条）**
- 实物状况：土地+建筑物详细描述
- 区位状况：位置、交通、配套、环境
- 权益状况：权属、规划条件、他项权利

**B. 市场背景分析（7.0.10条）**
- 宏观经济形势（GDP、利率、政策）
- 当地房地产市场状况
- 同类房地产的市场供求分析
- 价格走势和典型案例

**C. 最高最佳利用分析（7.0.11条，土地估价）**
- 法律上允许
- 技术上可能
- 财务上可行
- 价值最大化

**D. 估价方法适用性分析（7.0.14条，非第1章总则规范）**
- 逐一分析每种方法是否适用及理由
- 所选方法的理论依据

**E. 估价测算过程（7.0.12条，核心）**
- 各方法完整的测算轨迹
- 参数来源和取值依据
- 引用各测算技能的 Excel 结果
- 红线检查记录

**F. 估价结果确定（7.0.15条）**
- 各方法结果对比
- 差异原因分析
- 权重分配理由
- 最终估价结果

#### 3.7 ⚠️ 跨方法数据一致性（关键约束）

**不同估价方法中对同一估价对象的基础数据必须保持一致：**

| 数据项 | 一致性要求 | 检查方式 |
|--------|----------|---------|
| 建筑面积 | 所有方法使用同一数值 | 与权属证书记载核对 |
| 土地面积 | 所有方法使用同一数值 | 与权属证书记载核对 |
| 用途 | 所有方法使用同一用途 | 证载用途与实际用途一致 |
| 价值时点 | 所有方法同一时点 | 年月日完全一致 |
| 价值类型 | 所有方法同一价值类型 | 定义和内涵一致 |
| 土地剩余年限 | 收益法/成本法一致 | 从权属证书统一提取 |
| 报酬率/资本化率 | 如多方法使用，含义应一致 | 注明定义和取值依据 |

**不一致时必须在技术报告中说明原因。**

### Step 5: 自定义调整

支持以下自定义（见第三章模板自定义）：

1. **模板变量替换**：`{{估价对象}}`、`{{估价目的}}` 等占位符自动替换
2. **章节增删**：简要报告跳过技术报告章节
3. **方法选择**：根据实际使用的方法生成对应测算章节
4. **格式切换**：Markdown→Word→HTML→PDF→Dashboard 任意切换
5. **样式自定义**：字体、字号、页边距、公司 Logo 等
6. **批量生成**：同一模板 + 多套数据 = 批量报告

### Step 6: 多格式输出

| 格式 | 文件 | 适用场景 | 生成方式 |
|------|------|---------|---------|
| **Markdown** | `.md` | 默认格式，版本控制友好，可编辑 | 直接生成 |
| **Word** | `.docx` | 正式交付，打印签字 | python-docx |
| **HTML** | `.html` | 网页预览，浏览器查看 | 独立 HTML + 内嵌 CSS |
| **PDF** | `.pdf` | 归档，不可修改交付 | HTML→pdfkit/weasyprint |
| **Dashboard** | `.html` | 交互式数据看板，图表可视化 | Chart.js + 响应式布局 |

```python
# - 页眉：估价报告编号 + 机构名称
```

## 六、持续改进

After generating 估价报告, ask:

1. 是否有客户反馈需要调整的章节内容或格式？
2. 模板变量是否需要新增（如特定行业的参数）？
3. 哪种输出格式使用频率最高，是否需要优化该格式的样式？
4. 是否有规范更新导致报告结构需要调整？
5. 批量生成场景是否需要开发专门的批处理工具？
6. **收益法测算示例必须数据连贯** — 如果采用持有加转售模式，必须完整展示计算公式和参数，不可出现中间步骤的数据跳跃。
7. **总价和单价的一致性** — 最终结果中的总价÷面积必须等于单价（允许取整误差），不一致时必须说明原因。
