## ⚠️ CRITICAL: 路径选择与折旧判定 (READ FIRST)

1. **FIRST: 选择估价路径** — 优先选择房地合估路径（4.4.2条第1款）
2. **重置成本 vs 重建成本** — 一般建筑物选重置成本；历史/艺术/科学价值建筑物选重建成本（4.4.5条）
3. **必须到现场判断新旧程度** — 不得仅凭建成年代推算折旧（4.4.14条）
4. **NEVER 用成本法评估开发完成后价值** — 这是假设开发法的红线（4.5.7条），也约束成本法在开发项目中的使用边界
5. **NEVER 忽略销售税费和开发利润不计利息** — 两者不作为投资利息的计算基数（4.4.6条第2款）

**Why this matters:** 成本法不是"造价+利润"，而是模拟市场重新开发的全过程。遗漏期间费用（投资利息、销售费用）是成本法最常见的错误。

## Overview

成本法的核心逻辑：**成本价值 = 重置成本/重建成本 - 建筑物折旧**。适用于缺乏交易实例和收益数据的估价场景，是估价方法的"兜底选项"（4.1.2条第3款）。

**重置成本 vs 重建成本区别：**

| 类型 | 定义 | 适用 |
|------|------|------|
| 重置成本 | 用现代材料、技术、标准建造相同功能的建筑物 | 一般建筑物 |
| 重建成本 | 用与原建筑物相同的材料、技术、设计复制 | 历史/艺术/科学价值建筑 |

## 一、4 步工作流

### Step 1: 选择具体估价路径（4.4.2条）

```
估价对象包含土地和建筑物？
├─ 是 → 选择路径
│   ├─ 优先：房地合估路径
│   │   └─ 把土地当作原材料，模拟房地产开发全过程
│   └─ 房地分估路径
│       ├─ 土地重置成本（比较法/成本法/基准地价修正法）
│       └─ 建筑物重置成本或重建成本
└─ 否 → 单独测算
    ├─ 仅土地 → 重新开发土地的必要支出及利润
    └─ 仅建筑物 → 建筑物重置成本/重建成本 - 折旧
```

### Step 2: 测算重置成本或重建成本（4.4.3-4.4.6条）

#### 2.1 七项必要支出及应得利润

| 序号 | 构成项 | 说明 | 测算方法 |
|------|--------|------|---------|
| 1 | **土地成本** | 价值时点重新购置/开发土地的必要支出 | 比较法/成本法/基准地价法 |
| 2 | **建设成本** | 建安工程费+前期工程费+基础设施费 | 单位比较法/分部分项法/工料测量法 |
| 3 | **管理费用** | 开发建设过程中的管理支出 | 按建设成本比例 |
| 4 | **销售费用** | 营销推广费用 | 按售价比例/行业标准 |
| 5 | **投资利息** | 各项支出在建设期内的资金成本 | 利率 × 计息基数 × 计息期 |
| 6 | **销售税费** | 销售环节税费 | 按税法规定 |
| 7 | **开发利润** | 开发类似房地产的正常利润 | 计算基数 × 开发利润率 |

**投资利息计算要点（4.4.6条）：**
- 各项支出分别自发生时起至建设期结束时止计算计息期
- 销售税费和开发利润 **不计入** 投资利息的计算基数
- 各项支出应为正常客观的支出

#### 2.2 土地成本测算（4.4.4条）

| 方法 | 适用场景 | 要求 |
|------|---------|------|
| 比较法 | 土地市场活跃，有交易实例 | ≥ 3个可比实例 |
| 成本法 | 新开发土地 | 模拟土地开发全过程 |
| 基准地价修正法 | 有公布的基准地价 | 了解基准地价内涵 |

**房地分估路径特别注意**：土地状况为价值时点状况，使用期限为自价值时点起计的剩余年限。

#### 2.3 建筑物成本测算（4.4.5条）

| 方法 | 适用场景 | 说明 |
|------|---------|------|
| 单位比较法 | 一般建筑物 | 以单位面积造价比较 |
| 分部分项法 | 大型/复杂建筑 | 按分部分项工程分别估算 |
| 工料测量法 | 特殊建筑 | 按人工、材料逐项计算 |
| 政府重置价格调整 | 有公布重置价格 | 扣除土地价值后调整 |

### Step 3: 测算建筑物折旧（4.4.7-4.4.14条）

#### 3.1 三类折旧

| 折旧类型 | 定义 | 示例 |
|---------|------|------|
| **物质折旧** | 物理磨损、自然老化 | 结构老化、设备损坏、外墙破损 |
| **功能折旧** | 技术落后、功能不足或过剩 | 户型过时、层高低、无电梯 |
| **外部折旧** | 外部环境不利变化 | 污染源新增、规划变更、周边衰落 |

#### 3.2 三种折旧方法

| 方法 | 原理 | 适用 |
|------|------|------|
| **年龄-寿命法** | 直线法或成新折扣法 | 一般建筑物，折旧规律 |
| **市场提取法** | 从交易实例反推折旧 | ≥ 3个含类似折旧建筑物的可比实例 |
| **分解法** | 逐项分解折旧→可修复/不可修复 | 折旧因素复杂的建筑 |

#### 年龄-寿命法公式

**直线法（4.4.9-1）：**
```
V = C - (C - S) × t / N
```
**成新折扣法（4.4.9-2）：**
```
V = C × q
```

符号说明：
- V — 折旧后价值
- C — 重置成本或重建成本
- S — 预计净残值
- t — 有效年龄（实际年龄 ± 加减调整）
- N — 经济寿命
- q — 成新率

#### 3.3 分解法核心规则（4.4.13条）

```
修复成本 ≤ 修复带来的价值增加 → 可修复折旧（折旧额 = 修复成本）
修复成本 > 修复带来的价值增加 → 不可修复折旧（另行测算）
```

#### 3.4 现场查勘要求（4.4.14条）

- **必须到现场**观察、判断建筑物实际新旧程度
- 结合建成时间、使用状况、维护更新改造情况确定折旧额或成新率
- 不得仅凭建成年代推算

### Step 4: 计算成本价值（4.4.15-4.4.17条）

```
房地合估路径：成本价值 = 房地产重置成本/重建成本 - 建筑物折旧
房地分估路径：成本价值 = 土地重置成本 + 建筑物重置成本/重建成本 - 建筑物折旧
仅土地：成本价值 = 重新开发土地的必要支出及应得利润
仅建筑物：成本价值 = 建筑物重置成本/重建成本 - 建筑物折旧
```

**特别情形：**
- 在建工程/新近开发完成 → 可不扣折旧，但有减价因素须调整（4.4.16条）
- 权益状况 ≠ 无租赁/抵押/查封 → 对成本价值进行相应调整（4.4.17条）
- 土地使用权届满无偿收回 → 经济寿命替换为建设完成至届满的时间（4.4.11条）

## 二、关键约束

| 约束 | 出处 |
|------|------|
| 优先选择房地合估路径 | 4.4.2-1 |
| 一般建筑物宜测重置成本，历史建筑宜测重建成本 | 4.4.5-1/2 |
| 各项支出应为正常客观值 | 4.4.6-1 |
| 销售税费和开发利润不计入投资利息计算基数 | 4.4.6-2 |
| 各项支出计息期分别自发生时起至建设期结束止 | 4.4.6-3 |
| 必须到现场判断折旧 | 4.4.14 |
| 市场提取法折旧 ≥ 3个可比实例 | 4.4.12 |

### 3.2 切换估价路径

模板默认使用**房地合估路径**。用户切换方式：

**切换为房地分估路径：**
1. Sheet1 行5（土地成本）填入用比较法/成本法/基准地价法测算的土地重置成本
2. Sheet1 行6（建设成本）仅填建筑物部分
3. 投资利息在合估路径按土地+建设分别计息，分估路径仅建筑物建设期计息
4. Sheet3 成本价值自动重算

**仅估建筑物（不含土地）：**
1. Sheet1 行5 土地成本填 0 或删除
2. Sheet1 行6 填建筑物重置成本
3. 跳过土地相关支出（管理费基数调整为仅建设成本）

### 3.3 切换折旧方法

Sheet2 行4 设置折旧方法下拉框：
- **年龄-寿命法** → 填写行6-8，折旧合计取 B12
- **成新折扣法** → 填写行9，折旧合计取 B13
- **分解法** → 填写行15-17，折旧合计 = SUM(B15:B17)

折旧合计公式需按选定方法改写为 IF 嵌套：
```
=IF(B4="年龄-寿命法", B12, IF(B4="成新折扣法", B13, SUM(B15:B17)))
```

### 3.4 自定义成本构成项

模板默认列出 7 项必要支出，用户可：

- **增加成本项**：在行11 后插入行（如"城市基础设施配套费"），合计公式自动扩展
- **合并成本项**：将不适用项填 0 或隐藏行
- **调整计算基数**：管理费 = `B6*管理费率`，如果建设成本构成变化，调整公式中的 B6 引用
