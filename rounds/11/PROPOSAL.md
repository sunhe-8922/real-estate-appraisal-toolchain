## 二、假设（H11）

**把生成器末节点同步为整改形态、并用生成器输出重写冻结载体后：
① 生成器输出与冻结载体字段级全等（无漂移可言）；② 全链无重复 target；
③ 再漂移被机器拦截（常驻门禁 + 负向验证证明旧形态回来必红）；④ 变异与回归不破坏。**

| 项 | 内容 |
|---|---|
| 改什么 | ① `scripts/extract_calculation_chain.py`：`CORE_NODES` 末项 `result.totalValue`→`result.finalUnitValue`（target 唯一，派生单价描述）；`_NODE_OVERRIDE_REFS` 末项公式改 `=ROUND({{finalTotal}}/{{area}},0)`；② `outputs/calculation_chain.json` 由修复后的生成器重生成覆盖（字节级对齐 = 同步的机器证明）；③ 新增 `tests/test_generator_fixture_parity.py` 常驻门禁（奇偶 + 末节点形态 + target 唯一 + 负向验证 4 断言） |
| 为什么 | R10 已证明：豁免删除后旧形态可被拦截，但生成器还在发旧形态——等于门禁拦截的正是自家生成器的输出。三例载体分裂指向同一教训：同步必须覆盖所有载体，最后一个也不能留 |
| 预期收益 | 载体分裂根除（生成器输出 == 冻结载体，字节级）；再漂移即红灯（奇偶断言）；旧形态回来必红（负向验证，依赖 R10 删豁免） |
| 风险 | 低：模板 xlsx 只读；生成器改动仅末节点（其余 7 节点本就逐字一致，比对已证明）；`round11-baseline` tag 可回滚 |
| 验证成本 | 极低：本地重生成 + 比对 + 回归 + 变异 ×3 |

**单一变量**：「生成器末节点旧形态」。冻结载体重写不是第二变量——它是同步的验证手段（用生成器输出覆盖 = 证明两者此后不可能独自漂移）。门禁新增是本假设的固化形式，与 H8 把人工审查升级为门禁同构。**不动** fixture 的 `income.value`（H12，转下轮）。
